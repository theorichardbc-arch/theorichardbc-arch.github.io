# theorichardbc-arch.github.io

## Organisation

- `index.html` : accueil
- `core/` : a-propos, contact, mentions, liens, guide, bientot
- `projets/` : projets, alpes, projets-professionnels
- `textes/` : ecriture
- `photos/` : `portfolio.html`, `archives.html` (archives photo) et `images/` (originaux + `thumbs/`)
- `prestations/` : prestations, ateliers-labo, seances-photo
- `assets/css/style.css` : feuille de style commune
- `documents/` : PDF (CV)
- `404.html` : redirige les anciennes URLs racine (ex. `/contact.html`) vers les nouveaux dossiers ; à mettre à jour si une page change de dossier.
